# Omarchy MX Mac 4.0.4-mac.1

Unreleased preparation based on upstream Omarchy v4.0.4. This version is not
published to a public update or installation channel.

## Changes

- Import upstream's x86 kernel changes: the `linux-omarchy` kernel, matching
  headers as a base guarantee, and the retired Panther Lake kernel swap.
- Skip both new kernel migrations on Apple Silicon, which keeps its Asahi or
  Aurora kernel and GRUB boot setup unchanged.

## Validation

Source tests for the new migrations, the Asahi migration policy, hardware
setup and the package lists pass. Signed candidates, VM acceptance and an M1
Pro upgrade must be recorded before publication. See
[the preparation record](4.0.4-mac.1-preparation.md).
